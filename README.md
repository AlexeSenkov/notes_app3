# Практическая работа №3. Заметки

Приложение на Flutter. Чтобы записать что-нибудь, введи текст и нажми «Добавить». Новая заметка появится в начале списка.

| Действие с заметкой | Результат |
| --- | --- |
| Нажать | Открывается полный текст. |
| Нажать два раза | Строка подсвечивается жёлтым и появляется звезда. |
| Удерживать | Текст появляется в поле ввода. Кнопка «Сохранить» обновляет выбранную заметку. |
| Смахнуть влево | Заметка удаляется. |
| Смахнуть вправо | Звезда исчезает. |

Заметки хранятся в памяти, пока работает приложение.

## Запуск

```sh
flutter pub get
flutter run -d chrome
```
